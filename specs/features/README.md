# Feature Specifications

New features and significant changes are specified here **before** they are built, using
[`../templates/feature-spec.md`](../templates/feature-spec.md). The step-by-step process is in
[spec-first-workflow.md](../process/spec-first-workflow.md#2-creating-a-feature-spec-step-by-step).

Existing behaviour lives in [`../domains/`](../domains/). Once a feature ships and stabilises,
its rows may stay here (linked from the domain spec) or move into the domain spec. Moving a row
keeps its ID: re-register the prefix to the new file.
